# Карточка товара — Teaboom.ru

Тестовое задание на позицию HTML-верстальщик / Frontend-верстальщик.
Вёрстка верхней части карточки товара «Ананасовый улун» с рабочим переключателем фасовки.

**Демо:** https://khusnutdinovilm.github.io/teaboom-product-card/

## Стек

- HTML5, семантическая разметка
- SCSS (БЭМ, модульные партиалы, дизайн-токены)
- Vanilla JS (без фреймворков)
- Vite — dev-сервер, компиляция SCSS, production-сборка

## Запуск

```bash
# установка зависимостей
npm install

# режим разработки (http://localhost:5173)
npm run dev

# production-сборка в папку dist
npm run build

# локальный предпросмотр собранной версии
npm run preview
```

## Реализовано

- адаптивная вёрстка (проверено на 1440 / 768 / 375);
- переключатель фасовки: при выборе обновляются цена, старая цена, артикул и выделяется
  активный вариант;
- выбранное состояние фасовки — на чистом CSS через `:checked`, JS отвечает только за цифры;
- состояния кнопки «В корзину»: `hover` / `active` / `focus-visible`;
- семантическая разметка (`article`, `nav`, `fieldset`/`legend`, `del`) и базовая доступность
  (навигация с клавиатуры, `alt`, видимый фокус).

## Решения по реализации

- **Фасовки — группа `<input type="radio">` в `<fieldset>`**: клавиатурная навигация и озвучка
  скринридером из коробки, выбранное состояние оформляется без JS.
- **Данные фасовок хранятся в `data-*`** прямо на радио-кнопках — единый источник правды,
  JS ничего не дублирует.
- **Цена форматируется единообразно** (`formatPrice`) в русской типографике —
  неразрывный пробел перед `₽`, разделитель тысяч, два знака.
- **Дизайн-токены** (цвета, отступы, радиусы, брейкпоинты) вынесены в `styles/variables`,
  «магических» значений в блоках нет.
